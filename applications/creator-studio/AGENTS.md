# Creator Studio authoring contract

- Product authority: `documentation/creator-studio/product-contract.md` and the
  linked Worldwright professional-practice account. These publication copies
  identify their canonical corpus owners in `documentation/canonical-source-map.json`.
- All new application semantics, definitions, UI, styles, compilation,
  decompilation, standards, commentary, workflow, exchange and acceptance policy
  are Encounter source under the retained selected frontend.
- The bootstrap and vendor mechanisms are reused byte-for-byte from the
  inspected Usewords predecessor. No new handwritten JS, MJS, CJS, opaque
  callbacks or executable JSON module owners. Do not edit native mechanisms to
  hide an application fault or invent a browser permission.
- `dist` is derived output. Never edit it or use it as source.
- Shared edits use the retained `ws.apply` to `ec.patch` correspondence route.
  Preview, local acceptance, release and external publication remain distinct.
- Test new policy in Encounter, including refusal without mutation and replay.
  Retain the 20,000,000 execution budget. Record bounded capacity changes in
  Encounter explicitly; do not silently weaken tests or source authority.
- Persisted attribution is user-supplied unless verified by an actual identity
  capability. Portable packets are not authenticated collaboration. Package
  exchange and local commercial records are not payment settlement.
- Record supported formats and unimplemented adapters honestly. A placeholder
  or success notice is not a completed operation.
- Keep the predecessor application and canonical personal site untouched.
