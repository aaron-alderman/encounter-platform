# Private Usewords transport

This service hosts the private Usewords workspace and verifies Sourcery
Google workspace sessions with the existing AppDev observer. Membership,
observer configuration, and SQLite stores are private deployment inputs.

For the application, migration, and deployment instructions see the
[Usewords AppDev pilot](../usewords-lightning/platform/README.md#hosted-appdev-pilot).
The former pilot bookmark opens Usewords for members. Its original SQLite
store can be retained privately as the migration source.
