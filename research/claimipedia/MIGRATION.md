# Claimipedia server source workspace

This is an editable copy of the selected old Claimipedia source, corpus, and
supporting research. Relative paths match the Windows Sourcery workspace. The
main application and data are under `sourcery-applications/applications/claimipedia`.
The corresponding published release files are under `sourcery-applications`.
The active Encounter preview lives separately in
`../applications/encounter-claimipedia`.

The transfer includes the full legacy Claimipedia directory, the additional
top-level Claimipedia research subtree, the referenced physics corpus, six
declared legacy source plugins, the scientific inquiry source package, and
Claimipedia-specific releases, tools, tests, deployment source and receipts.
The snapshot inventory is in `.migration/SHA256SUMS`. The compressed original
in `.migration/claimipedia-original.tar.gz` retains the imported bytes.

The live server services and Encounter preview were outside the transfer.
Repository history, dependency installations, machine-local deployment
configuration, runtime state and generated caches were outside scope. Two
exact synthetic calibration signing fixtures are retained because their
source explicitly forbids measurement use. They carry no operational role
in this workspace.

The Spin(2,3) historical manifest resolves to 735 hash-matching source and
evidence files in the copied tree. Four listed Python bytecode cache files
are excluded. The historical manifest remains intact.

The migration validates bytes and known paths. The old source and evidence
remain attributed to their original owners and dispositions. Any later
Encounter projection should select the needed collection explicitly, with
released claims, Frontier assessments, research, and application authority
records kept distinguishable.
