# Does V/V+ find cross-domain Claimipedia connections ordinary search misses?

## Question and sample

Compare manually coded V/V+ retrieval with ordinary ranked lexical search on the same cross-domain candidate pool. The intended use is to surface a structural analogy or counterpoint that gives a reader a concrete question about the query. A 2 from a method-blinded reviewer is the primary relevance outcome.

Use both parts of the Claimipedia identity map. Set three operational domain bins: AI and society (aiInquiry or aiFutures namespace), Christian ethics and theology (contribution namespace with one of the frozen theology scope cues), and institutional design (the relationalInstitution namespace under Claimipedia). These are editorial domains, not independent sources. Select records meeting the frozen agency/authority vocabulary screen and minimum of 12 word tokens, excluding records ending in a question mark. Form transitive components using normalized exact text and confirmed proposition equivalence. Exclude the four discussion examples, the earlier six experiment samples, and any intersecting components. Keep at most one per remaining component. For each domain in the frozen order, select three queries then ten candidates using the SHA-256 rank of the literal `claimipedia-vv-cross-domain-v1|` plus partition name (`queries` or `candidates`), a literal pipe and the ID. Freeze code, sample, rubric and input hashes before displaying the selected texts. Use all nine queries and all 30 candidates. Query text is the unedited source claim. The task is to find an analogy or relevant counterpoint to that text. Both methods exclude the query's own domain.

## Ranking and blinding

Ordinary search uses SQLite FTS5 BM25 with Porter stemming on raw candidate texts. Query the OR of unique non-stopword tokens from the raw query. Zero-fill unmatched eligible records. V/V+ uses up to two frames per record in the frozen vocabulary, with fields for whose interest changes, the interest, direction of change, relational mechanism and directed coupling. Code an empty frame list when the source supports no such mapping. The same investigator manually annotates candidate frames before opening the query texts, freezes them by SHA-256, then annotates and freezes query frames. The investigator knows the domain and previously encoded candidates. No changes based on retrieval results or reviewer feedback. The score is the maximum frame similarity, using exact field weights 1, 3, 1, 2, 3 and a bonus of 2 for matching both interest and coupling. Zero-fill empty comparisons. Use the same salted deterministic tie-break for both methods. Return the top three per query per method.

Pool and deduplicate pairs for the reviewer, give each an opaque ID, and shuffle by frozen hash. Use a separate fresh reviewer without the prior conversation, method labels, ranks, frames, source identifiers or unpooled candidates. The reviewer sees the rubric and each query and candidate text. Rank lists remain with the runner. Preserve every judgment and reason. The study uses one reviewer. Reviewer identity and the limits of blinding will be reported.

## Outcomes

Report relevant pairs (grade 2) in each arm's top three and query coverage, plus grade-2 pairs unique to each arm's top three and the number of queries with those unique findings. “Misses” means missing the other method's top three on this pool. Grade 1 counts as adjacent and will be reported separately. Do not estimate corpus recall or score unreviewed pairs as irrelevant. For evidence of additional retrieval value, require at least three V/V+-only relevant pairs across at least two queries. Report the symmetric result for ordinary search and whether V/V+ improves total top-three relevance or provides complementary findings. Use no significance tests. Report the manual coding and cue-enriched sample as costs and limits, and disclose near paraphrases or domain overlaps if encountered.
